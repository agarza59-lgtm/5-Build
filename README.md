# 5-Build
Film and Creative Arts Website
Project Description
This project is a responsive website highlighting film screenings, creative workshops, and opportunities for collaboration. The website uses HTML and CSS to provide a layout that adapts to mobile and desktop screens.
Pages Include; Home (index.html), Film Screenings (screenings.html), Workshops (workshops.html ), Collaborations (collaborations.html).
Published Website URL: https://agarza59-lgtm.github.io/5-Build/index.html

AI Use Statement: I used ChatGPT to assist with generating written content for the Film Screenings, Workshops, and Collaborations pages. I also used ChatGPT for guidance and troubleshooting with HTML, CSS, and GitHub. I implemented and tested the code myself.
